# دليل الاختبار - Test Guide

## متطلبات التشغيل / Requirements

### 1. متغيرات البيئة / Environment Variables

أنشئ ملف `.env` في المجلد الرئيسي وأضف:

```env
# OpenRouter API Key (مطلوب للذكاء الاصطناعي)
OPENROUTER_API_KEY=your_openrouter_api_key_here

# App URL (اختياري)
NEXT_PUBLIC_APP_URL=http://localhost:3000

# MongoDB (اختياري - سيستخدم MockDB تلقائياً إذا لم يكن موجوداً)
# USE_MONGODB=false
# MONGODB_URI=mongodb://localhost:27017
```

### 2. تشغيل الخادم / Start Server

```bash
npm run dev
```

الخادم سيعمل على: `http://localhost:3000`

## نصائح الاختبار / Testing Tips

1. **ابدأ بأسئلة بسيطة** ثم انتقل للأسئلة المعقدة
2. **اختبر البحث** بمعايير مختلفة (الموقع، السعر، عدد الغرف)
3. **اختبر حجز المواعيد** بتواريخ وأوقات مختلفة
4. **تحقق من الردود بالعربية** - يجب أن تكون جميع الردود بالعربية
5. **اختبر الأخطاء** - جرب أسئلة غير واضحة أو معايير غير موجودة

## حل المشاكل / Troubleshooting

### مشكلة: "Failed to fetch conversations"
**الحل:** تأكد من أن MockDB يعمل (يستخدم تلقائياً إذا لم يكن MongoDB متاحاً)

### مشكلة: "API request failed"
**الحل:** تحقق من `OPENROUTER_API_KEY` في ملف `.env`

### مشكلة: لا توجد ردود من AI
**الحل:** 
- تحقق من اتصال الإنترنت
- تحقق من صحة API Key
- راجع سجلات الخادم (console logs)
