How Many Users Can It Handle?

The true bottleneck for AI chat is usually response-generation concurrency, not just ingress. With 60 workflow workers, estimated throughput is:

  • If avg generation is 8s: about 450 messages/min (~7.5 msg/s).
  • If avg generation is 12s: about 300 messages/min (~5 msg/s).
  • If avg generation is 15s: about 240 messages/min (~4 msg/s).

Equivalent active users at 1 msg/user/min: approximately 240 to 450 active users without queue growth.

Equivalent active users at 1 msg/user/5min: approximately 1200 to 2250 active users.

Answer

Right now, the system can handle ~1000 request batches at parallel 20 reliably, but it cannot reliably handle 10k burst at parallel 200.

Practical current capacity for real AI response flow is estimated at ~240 to 450 messages/min (depending on model response time), not 10k simultaneous burst.
