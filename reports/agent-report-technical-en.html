1) Core Upgrades Delivered

  • Global cross-user property search cache with TTL and hit tracking.
  • Smart search pipeline now reuses shared cache before per-user cache.
  • Refresh behavior preserved: refresh/bypass does not reuse stale cache.
  • New loan capability tools: live loan search + mortgage calculator.
  • Improved memory extraction for long conversations and user recall.

2) Performance/Scale Impact

  • Reduces duplicate web search calls across users with same query intent.
  • Improves latency on repeated intents via cache-first retrieval.
  • Lowers token and search cost by reusing normalized result payloads.
  • Supports high-concurrency query stacks with deterministic cache keys.

3) Architecture Changes

Area Change Outcome
Schema globalSearchCache table added. Shared cross-user cache persistence.
Service APIs getGlobalSearchCache, upsertGlobalSearchCache, trackGlobalSearchCacheHit, clearGlobalSearchCache. Cache lifecycle control + admin invalidation.
Property Tool Flow smartPropertySearch now checks global cache, then user cache, then web fallback. Faster repeated searches, fewer external calls.
Loan Tooling searchSaudiLoans + calculateSaudiLoan added. End-to-end financing assistance in-agent.
Memory Inference Added extraction for timeline, financing mode, contact preference, and name variants. Better long-session personalization and recall.
